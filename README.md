# CineAcervo

Aplicativo Flutter que exibe um catálogo de filmes.

- Tela inicial com o catálogo de filmes e busca por título.
- Tela de detalhes com capa e fotos de cenas, sinopse, diretor(es), atores principais, ano de lançamento, nota do IMDb e comentários dos usuários com suas notas.
- Login simulado (usuário fictício) que libera: avaliação de 1 a 5 estrelas, publicação e exclusão de comentários próprios e favoritar filmes.

Os dados são lidos de arquivos JSON estáticos em `recursos/jsons`.

## Execução

```
flutter pub get
flutter run
```
